Eight Parts,
One Engine

Each crate owns a specific subsystem. Together they form the full inference pipeline.

GF
gguf parser

GGUF v3 file format parser. Memory-mapped I/O, 13 metadata types, 42 tensor types, SIMD-parallelized dequantization.

v3 format mmap I/O 42 dtypes dequant
GM
ggml core

Core tensor library. Multi-dimensional arrays, DAG computation graphs. Foundation type for all backends.

Tensor DType Graph DAG zero deps
CP
ggml-cpu backend

CPU compute backend. Block-tiled matmul with AVX 8-wide → SSE4.2 4-wide → scalar fallback. std::thread::scope parallelism.

AVX SSE4.2 block-tiled 16×16 tiles
CU
ggml-cuda gpu

CUDA backend via cuBLAS. GPU tensor operations, VRAM tracking, device transfer. GTX 1050 (sm_61, 2GB) target.

cuBLAS VRAM tracking sm_61 stub mode
LM
LLaMa engine

The inference engine. Full transformer forward pass — RMSNorm, RoPE, multi-head GQA attention, SwiGLU FFN, KV cache, flash attention. Supports LLaMa, Mistral, Phi, Gemma, Qwen2, StableLM.

transformer flash attn GQA KV cache 8 archs profile
CM
common utils

Shared utilities — clap argument parsing, sampling config (temperature, top-k, top-p, repeat penalty), chat templates.

args sampling templates
CL
LLaMa-cli binary

CLI binary. Interactive stdin mode, single-prompt mode, streaming token output, configurable context window.

interactive streaming single-prompt
SV
LLaMa-server api

Axum-based HTTP server. POST /completion (JSON + SSE streaming), GET /health. Tokio + futures async runtime.

REST API SSE streaming axum /health

Quick Start

From clone to inference in four commands.

# Build (release, optimized)
$ cargo build --release --workspace
# Run CLI inference
$ LLaMa-cli -m model.gguf -p "Hello, world!" -n 128
# Start HTTP server
$ LLaMa-server -m model.gguf --host 0.0.0.0 --port 8080
# Run all tests
$ cargo test --workspace --verbose
